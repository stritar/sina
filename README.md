# sina
The governed design system for AI agents. SINA uses strict Zod schemas to validate LLM intents before rendering secure React primitives.

SINA is free and built for startups and individuals who want to start their project on a design system with governance built in — adopting agentic UI generation on primitives that do more than sit there statically, without building the governance layer themselves.
