title: Scales & index

Color has its [own page](/docs/tokens/color). Everything else is a scale — a small,
fixed set of steps you compose from. Sticking to the steps is what keeps a UI
rhythmic instead of arbitrary.

## Typography

Two typefaces (Rubik for text, IBM Plex Mono for code) and a type scale.

| Family | Tokens |
|---|---|
| Size | `--sina-text--xs` · `ui` · `sm` · `base` · `lg` · `xl` · `2xl` · `3xl` · `4xl` · `5xl` |
| Weight | `--sina-font-weight--regular` · `medium` · `semibold` · `bold` |
| Line height | `--sina-leading--none` · `tight` · `snug` · `normal` · `relaxed` |
| Tracking | `--sina-tracking--tight` · `normal` · `wide` |
| Family | `--sina-font--sans` · `--sina-font--mono` |

## Spacing

An 8-point grid on a 4px base, with a few half-steps for tight controls.

| | Tokens |
|---|---|
| Steps | `--sina-space--0` … `--sina-space--24` |
| Half-steps | `--sina-space--0_5` · `--1_5` · `--2_5` |
| Control height | `--sina-space--7` (28px) |

## Radius, border & shadow

| Family | Tokens |
|---|---|
| Radius | `--sina-radius--none` · `xs` · `sm` · `md` · `lg` · `xl` · `2xl` · `full` |
| Border width | `--sina-border-width--0` · `1` · `2` · `4` |
| Shadow | `--sina-shadow--xs` · `sm` · `md` · `lg` · `xl` · `focus` · `focus-ring` |

## Motion & layering

| Family | Tokens |
|---|---|
| Duration | `--sina-duration--instant` (80ms) · `fast` · `base` · `slow` |
| Easing | `--sina-ease--standard` · `out` |
| Z-index | `--sina-z--base` · `dropdown` · `overlay` · `modal` · `toast` |

<Callout variant="tip" title="Reduced motion is automatic">
  Durations collapse to zero under `prefers-reduced-motion` at the token layer — so
  every component respects the setting without any per-component code.
</Callout>

## The token index

Every family, one table — pick the namespace, get the tokens.

| Namespace | Controls |
|---|---|
| `--sina-color-*` | Ramps, semantic roles, status ([Color](/docs/tokens/color)) |
| `--sina-text-* / font-* / leading-* / tracking-*` | Typography |
| `--sina-space--*` | Spacing |
| `--sina-radius--* / border-width--*` | Corners & borders |
| `--sina-shadow--*` | Elevation & focus |
| `--sina-duration--* / ease--*` | Motion |
| `--sina-z--*` | Stacking order |
