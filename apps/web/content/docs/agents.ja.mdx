AI はあなたのスタイルガイドを読み、そして無視できます。しかし、リクエストと画面のあいだで
コードとして実行される規則は無視できません。それこそが SINA がもたらす転換です。規則は AI
が参照する文書ではなく、AI が通り抜けるゲートなのです。AI が*読める*デザインシステムは提案
にすぎませんが、AI が*通り抜けねばならない*デザインシステムは保証となります。入念に書かれた
プロンプトでも、誤読されたり、忘れられたり、巧妙な入力によって上書きされたりする可能性が
あります。しかし強制される規則は、言いくるめて退けることはできません。

## エージェントが送信するもの

SINA はモデルにインテント動詞のメニュー、すなわちマニフェストを渡します。

```ts
[
  { intent: "wire_transfer", kind: "governed", summary: "Move money by wire" },
  { intent: "list_transactions", kind: "display", summary: "Show recent activity" },
  // …
]
```

モデルは 1 つの動詞を選び、その props を与えます。モデルは目標を記述しているのであって、
画面を組み立てているのではありません。

## エージェントに決してできない 2 つのこと

- **コンポーネントを指名できません。** マニフェストにあるのは動詞であって、コンポーネント
  ではありません。SINA はゲートが実行された*あとで*動詞をコンポーネントに対応づけるため、
  モデルはそもそも生の確認ボタンが存在することを知りません。
- **読み取りのためのデータを捏造できません。** モデルが残高や取引一覧を*表示*するよう求める
  と、実際の値を供給するのはあなたのサーバーです。モデルは*何を*表示するかを選びますが、
  *数値が何であるか*は決して選びません。

この 2 つを 60,000 ドルの電信送金に当てはめてみましょう。モデルは確認ボタンをレンダリング
できず（コンポーネントを一度も選んでいません）、送金を自ら承認することもできず（承認には
*別の*人物が必要で、サーバー側で検証されます）、少額を承認してから多額にすり替えることも
できません（承認は正確な条件に結び付けられており、それをサーバーが再計算します）。

<Callout variant="enforced" title="求めることは行うことではない">
  エージェントは何でも*求める*ことができます。しかし、ゲートが許可しなかったことは何も
  *行う*ことができません。提案とレンダリングのあいだのその隔たりにこそ、SINA の安全性の
  すべてが宿ります。
</Callout>

## 試してみる

このデモは**本物のゲート**を実行します。あなたのサーバーが実行するのと同じコードを、実行を
押したときにサーバー上で動かします。敵対的なストリームが捏造された「確認」ボタンを紛れ込ま
せようとしますが、厳格なパースは、いかなる値が読み取られる前に余分なフィールドを捨てます。
リクエストを切り替えて、境界が実際にどこに引かれるのかをご覧ください。

<GovernanceDemo
  scenario="fabricated-confirm"
  scenarios={["fabricated-confirm", "small", "over-limit", "self-approval"]}
/>

エミュレータには 3 つのモードがあります。mock（録画されたリクエスト）、direct（手書きの
JSON）、live（本物のモデル）です。ゲートはリクエストがどこから来たかを気にしないため、
3 つのいずれでも決定は同一です。完全なウォークスルーは[6 万ドルの電信送金](/docs/governance/wire-transfer)をご覧ください。

## エージェントが読めるドキュメント

コーディングアシスタントをここに向ければ、ドキュメントを直接取り込めます。

| リソース | 何か |
|---|---|
| `/llms.txt` | すべてのページを厳選した索引。LLM がクロールするためのもの。 |
| ページごとの `.md` | すべてのページには `/llms/docs/…` 配下に生の Markdown の双子があります。 |

この索引は、SINA 自身の精神に沿ったエージェント向けの前置きから始まります。UI を
**インテント**として、すなわち動詞と props として発し、決して捏造したコンポーネントとして
発してはならない。それをサーバー側のゲートに送る。登録済みのインテントを優先する。ほかの
ものはすべて拒否されるからだ。
