<Prereqs>
- **Node 20+** et un gestionnaire de paquets (pnpm, npm ou yarn).
- Une application React capable d'exécuter du code serveur (un projet Next.js App Router est idéal).
- Vous n'avez **pas** besoin d'un agent d'IA ni d'une clé LLM.
</Prereqs>

## Brancher les feuilles de style

Importez les styles de tokens et de composants une seule fois, dans cet ordre. Le
reset est placé dans un layer, de sorte que les styles propres à votre
application l'emportent toujours sur lui.

```ts
// app/layout.tsx
import "@sina-design-system/theme/reset.css";
import "@sina-design-system/theme/css";
import "@sina-design-system/core/styles.css";
import "@sina-design-system/fintech-react/styles.css";
```

Voilà pour la configuration. À partir d'ici, les primitives fonctionnent seules ; le contrôle est facultatif.
