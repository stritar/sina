SINA is a **design system with a gate**. When an AI builds part of your app's
interface, SINA checks that request on your server first — and only lets safe,
accessible, on-brand components through.

A normal design system is a box of parts and a rulebook. It hopes everyone
follows the rules. SINA is different: the rules are **enforced by code**, so an
AI can't ship a broken or unsafe screen even if it tries.

<FlowDiagram />

## The problem it solves

AI agents can now build UI on the fly. That's powerful — and risky. An agent can
invent a "Confirm" button for a payment that was never approved, render a form
that a screen reader can't use, or show account data it shouldn't. Left alone, it
will eventually do all three.

SINA closes that gap. The AI never picks the component. It sends an **intent** — a
plain description of what it wants to show — and your server decides what actually
renders. Safe requests become real, accessible components. Unsafe ones are blocked
or redirected to a stricter, governed component. Nothing skips the check.

<Callout variant="governance" title="The one idea">
  The model proposes; the server decides; the screen only shows what passed. SINA
  calls this **validate, then mount** — check first, render second, never the
  other way around.
</Callout>

## Who it's for

SINA is **free**, and built for startups and individual builders who want a
governed design system without building the governance themselves. It ships
today for **fintech** — money movement, accounts, cards, disclosures — because
that's where getting it wrong is most expensive.

You don't need an AI agent, an LLM key, or a policy of your own to try it. The
docs run the real gate live, right in the page.

<Callout variant="note" title="Is SINA for you?">
  SINA fits if you generate UI with AI (or plan to) and can run a check on the
  server (a Next.js server action, a route handler). If you just want beautiful,
  accessible React components without the governance, you can use SINA's
  [primitives on their own](/docs/guides/primitives-without-governance) — no gate
  required.
</Callout>
