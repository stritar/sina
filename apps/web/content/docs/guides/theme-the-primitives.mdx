---
title: Theme the Primitives
description: Rebrand at the token layer with createTheme and themeVars — brand-open roles are open, governance-locked roles are reserved
---

SINA primitives are rebrandable, but only through the token layer — you never
edit a primitive to change its look. Dark mode is the proof: `theme.css` ships a
`[data-theme="dark"]` block that only reassigns `--sina-*` variables. A brand is
just another such block.

## Brand-open vs. governance-locked

The token contract is deliberately split:

- **Brand-open** roles are the rebranding surface — `bg` / `surface*` /
  `text*` / `border*` / `primary*` / `secondary*` / `success|warning|info*`,
  the chart series slots, plus `radius` / `space` / `text` / `font`.
- **Governance-locked** roles are reserved — `danger*`, `surfaceSecure`,
  `focusRing`, and the `intent-*` aliases. Rebranding these would let a theme
  quiet a security or accessibility affordance, so the typed API refuses them.

The lock is enforced on the **sanctioned path**: `BrandTheme` excludes the
locked roles, so `createTheme` rejects them at compile time. (Raw CSS can still
force a variable by specificity — the API simply will not help you do it.)

## `createTheme` and `themeVars`

`@sina-design-system/theme` exports two typed emitters over the brand-open set.
`createTheme` returns a scoped CSS rule string:

```ts
import { createTheme } from "@sina-design-system/theme";

const acme = createTheme(
  { colors: { primary: "#7c3aed" }, radius: { md: "0.5rem" } },
  { selector: '[data-theme="acme"]' },
);
// → '[data-theme="acme"] { --sina-color-primary: #7c3aed; --sina-radius--md: 0.5rem; }'
```

`themeVars` returns the same overrides as an inline-style object for React
`style={}` or CSS-in-JS:

```ts
import { themeVars } from "@sina-design-system/theme";

const vars = themeVars({ colors: { primary: "#7c3aed" } });
// → { "--sina-color-primary": "#7c3aed" }
// <div style={vars}>…scoped brand…</div>
```

## `[data-theme]` scopes

Both emitters take a selector so a brand composes with dark mode: scope the
overrides to `[data-theme="acme"]`, and the dark block still applies where it
matches. Default scope is `:root`.

## Status

The typed contract is **seeded** today (`packages/theme/src/create-theme.ts`,
with a partition test keeping the brand-open and locked sets from drifting). The
full packaging story — the prebuilt-CSS build guard, the `assertThemeContrast`
guard that fails a brand override which breaks a required fg/bg pairing, and this
guide going fully live — completes in **Phase 10 (Release Hardening)**.
