<Prereqs>
- **Node 20+** y un gestor de paquetes (pnpm, npm o yarn).
- Una aplicación React que pueda ejecutar código de servidor (un proyecto Next.js App Router es lo ideal).
- **No** necesitas un agente de IA ni una clave de LLM.
</Prereqs>

## Conecta las hojas de estilo

Importa los estilos de tokens y de componentes una sola vez, en este orden. El
reset está en una capa, así que los estilos propios de tu app siempre ganan
sobre él.

```ts
// app/layout.tsx
import "@sina-design-system/theme/reset.css";
import "@sina-design-system/theme/css";
import "@sina-design-system/core/styles.css";
import "@sina-design-system/fintech-react/styles.css";
```

Eso es toda la configuración. A partir de aquí las primitivas funcionan por sí solas; el control es opcional.
