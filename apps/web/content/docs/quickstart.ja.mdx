<Prereqs>
- **Node 20+** とパッケージマネージャー（pnpm、npm、または yarn）。
- サーバーコードを実行できる React アプリ（Next.js App Router プロジェクトが理想的です）。
- AI エージェントや LLM キーは**不要**です。
</Prereqs>

## スタイルシートを接続する

トークンとコンポーネントのスタイルを、この順序で一度だけインポートします。reset はレイヤー化されているため、アプリ自身のスタイルが常にそれに優先します。

```ts
// app/layout.tsx
import "@sina-design-system/theme/reset.css";
import "@sina-design-system/theme/css";
import "@sina-design-system/core/styles.css";
import "@sina-design-system/fintech-react/styles.css";
```

セットアップは以上です。ここからプリミティブは単体で動作します。ゲートはオプトインです。
