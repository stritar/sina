An AI can read your style guide and ignore it. It cannot ignore a rule that
runs as code between its request and the screen. That's the shift SINA makes:
the rules aren't a document the AI consults, they're a gate it passes through.
A design system an AI can *read* is a suggestion; one it must *pass through* is
a guarantee. And unlike a careful prompt — which can be misread, forgotten, or
overridden by a clever input — an enforced rule can't be talked out of the way.

## What the agent sends

SINA gives the model a menu of intent verbs — a manifest:

```ts
[
  { intent: "wire_transfer", kind: "governed", summary: "Move money by wire" },
  { intent: "list_transactions", kind: "display", summary: "Show recent activity" },
  // …
]
```

The model chooses one verb and supplies its props. It's describing a goal, not
building a screen.

## The two things it can never do

- **It can't name the component.** The manifest has verbs, not components. SINA
  maps the verb to a component *after* the gate runs — the model doesn't know
  the raw confirm button exists.
- **It can't invent the data for a read.** When the model asks to *show* a
  balance or a transaction list, your server supplies the real values. The
  model picks *what* to show, never *what the numbers are*.

Put those together on the $60,000 wire: the model can't render the confirm
button (it never chose components), can't approve the transfer itself (approval
requires a *different* person, checked server-side), and can't approve a small
amount then swap in a big one (the approval is bound to the exact terms, which
the server recomputes).

<Callout variant="enforced" title="Asking is not doing">
  The agent can *ask* for anything. It can't *do* anything the gate didn't
  allow. That gap — between proposing and rendering — is where all of SINA's
  safety lives.
</Callout>

## Docs your agent can read

Point a coding assistant here and it can consume the docs directly:

| Resource | What it is |
|---|---|
| `/llms.txt` | A curated index of every page, for an LLM to crawl. |
| Per-page `.md` | Every page has a raw-Markdown twin under `/llms/docs/…`. |

The index leads with an agent-facing preamble in SINA's own spirit: emit UI as
**intent** — a verb and props — never a fabricated component; send it to the
server-side gate; prefer the registered intents, because anything else is
denied.
