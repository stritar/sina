---
title: Intent registry
description: The verbs an AI can emit, and what each one mounts. This is the menu the model chooses from — it never names a component.
---

The registry maps every intent **verb** to its rule and the component SINA mounts.
The model picks a verb from this list (via `fintechIntentManifest()`); the gate
picks the component. A representative slice follows — the authoritative list is
`fintechIntentManifest()` in `@sina-design-system/fintech`.

## Governed (actions)

| Intent | Escalates to |
|---|---|
| `wire_transfer` | `SecureWireDialog` |
| `ach_transfer` · `p2p_payment` · `bill_pay` · `fx_convert` · `withdraw` | `GovernedActionDialog` |
| `add_payee` · `link_account` · `kyc` · `add_user` | `GovernedActionDialog` |
| `issue_card` · `card_control` · `change_limit` · `security_change` | `GovernedActionDialog` |
| `place_trade` · `enable_margin` · `credit_request` | `GovernedActionDialog` · `MandatoryDisclosure` |
| `disclosure` | `MandatoryDisclosure` |

## Display (reads)

| Intent | Mounts |
|---|---|
| `list_transactions` | `TransactionList` |
| `account_balance` | `BalanceCard` |
| `portfolio_holdings` | `PortfolioHoldings` |
| `spending_breakdown` · `budget_progress` · `cashflow_summary` | presentational reads |
| `list_cards` · `list_payees` · `upcoming_payments` · `watchlist` · … | presentational reads |

<Callout variant="note" title="Unknown verbs are denied">
  An intent that isn't in the registry is rejected as `UNKNOWN_INTENT` — and still
  audited. The default is deny, not pass.
</Callout>

Full details: [`@sina-design-system/fintech`](/docs/reference/fintech).
