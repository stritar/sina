## 用語集

| 用語 | 意味 |
|---|---|
| **インテント** | UI を表示するための AI の要求。動詞と props であり、決してコンポーネントではありません。 |
| **憲章** | 何が許可されるかを決める規則（スキーマ）の完全な集合。 |
| **ゲート** | すべてのインテントが通過するサーバー側のチェック。 |
| **インターセプト** | 何かがマウントされる前に、インテントをゲートに通すこと。 |
| **検証してからマウント** | SINA の中核となる規則。まずサーバーで検査し、その後にレンダリングします。 |
| **インターセプト契約** | 統一された結果の形。`{ valid, violations, requiredComponent }`。 |
| **違反** | ゲートが不正と判断した 1 つの事項。メッセージ、重大度、引用された標準を伴います。 |
| **重大度** | 違反がどれほど強く作用するか。`flag`、`escalate`、または `reject`。 |
| **エスカレーション** | ブロックされた要求を拒否する代わりに、より厳格なコンポーネントへ振り向けること。 |
| **統制された** | あるアクションに対する規則。ポリシーと、起こり得るエスカレーションを伴います。 |
| **表示 / 統制されない** | ある読み取りに対する規則。形状が検査されマスクされますが、決してエスカレーションされません。 |
| **墨消し** | 監査ログに保存される前に、機密データを除去/マスクすること。 |
| **監査イベント** | すべての決定が発行する記録。 |
| **フォーアイズ** | 承認者は起票者と異なっていなければならないという規則。 |
| **ペイロードバインディング** | 承認を正確な条件に結び付け、サーバー上で再計算すること。 |
| **マイナー単位** | 整数（セント）としての金額。ISO 4217 に準拠。浮動小数点はなし。 |
| **プリミティブ** | ヘッドレスでアクセシブルな core コンポーネント（Button、Dialog、…）。 |
| **トークン** | 名前付きのデザイン値（色、サイズ、フォント）を `--sina-*` 変数として表したもの。 |
| **ブランド開放 / ガバナンス固定** | 再テーマ化してよいトークンの役割と、安全のために予約されたものの対比。 |
| **マニフェスト** | AI が発行してよいインテント動詞のリスト。 |

## FAQ

**SINA を使うのに AI や LLM のキーは必要ですか？**
いいえ。ゲートはプレーンなオブジェクトで呼び出せますし、ドキュメントはキーなしでそれをライブ実行します。コンポーネントだけが欲しい場合は、[プリミティブを単体で使ってください](/docs/guides/adopt-incrementally)。

**SINA は fintech 専用ですか？**
今日のところ、はい。[ガバナンスの継ぎ目](/docs/reference/packages)はドメインに依存しないため、別のドメインは書き直しではなく[追加的](/docs/guides/extend-sina)です。まだ何も構築されていません。

**Next.js の外でも動作しますか？**
ゲートには、サーバー側のチェックを実行する場所が必要です。Next.js App Router が最もスムーズに適合しますが、チェックを実行できるサーバーであれば何でも機能します。コンポーネントはプレーンな React です。

**本番環境で使えますか？**
**0.1.0** で公開されているため、まだ初期段階です。ゲートとプリミティブはテスト済みです（敵対的スイートと自動アクセシビリティチェックを含みます）。監査証跡は、no-op のシンクを備えた定義済みの契約です。それに応じて評価し、[リリースと安定性](/docs/reference/changelog)を参照してください。

**ライセンスは何ですか？**
MIT で、無料です。SINA は、スタートアップや個人がガバナンス層を自分で構築することなく、統制されたデザインシステムを採用できるように存在します。

**ゲートはレイテンシを追加しますか？**
これは同期的なサーバー側のチェックで、スキーマのパースにポリシーを加えたもので、ミリ秒単位で測定されます。ゲート自体にモデル呼び出しはありません。

**SINA は AI を実行しますか？**
いいえ。あなたが自分のエージェントを実行し、SINA はその出力を統制します。モデルはインテントを提案し、SINA が何をレンダリングするかを決定します。
