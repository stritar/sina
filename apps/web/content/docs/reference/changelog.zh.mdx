## 稳定性与版本管理

SINA 尚处于早期阶段。版本遵循 semver，通过 Changesets 发布。

- **足够稳定，可放心构建**：令牌系统、基础组件（可访问、经过测试）、拦截契约以及 fintech
  关卡。它们具有可以依赖的形态和测试覆盖率。
- **仍在演进中**：审计追踪是一份已定义的契约，配有一个 no-op 接收端（持久化接收端已在规划中），主题契约的防护正在加固。
- **尚未构建**：第二个治理领域、一个 CLI，以及一个托管的文档助手。架构为它们预留了空间；但它们尚未到位。

<Callout variant="note" title="0.x 意味着预期会有变化">
  在 1.0 之前，次要版本可能带来破坏性变更。请固定你的版本，并在升级前阅读发布说明。
</Callout>
