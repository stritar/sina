<Prereqs>
- **Node 20+** und ein Paketmanager (pnpm, npm oder yarn).

## Stylesheets einbinden

Importieren Sie die Token- und Komponentenstile einmalig, in dieser Reihenfolge.
Das Reset liegt in einem eigenen Layer, sodass die eigenen Stile Ihrer App stets
über ihm gewinnen.

```ts
// app/layout.tsx
import "@sina-design-system/theme/reset.css";
import "@sina-design-system/theme/css";
import "@sina-design-system/core/styles.css";
import "@sina-design-system/fintech-react/styles.css";
```

Das war die Einrichtung. Von hier an funktionieren die Primitives eigenständig; der Kontrollpunkt ist optional.
