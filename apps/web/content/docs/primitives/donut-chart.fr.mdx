`DonutChart` est un [PieChart](/docs/primitives/pie-chart) avec un évidement
central, ce qui vous permet de placer un total ou un libellé au milieu.

## Utilisation

```tsx
import { DonutChart } from "@sina-design-system/core";

<DonutChart label="Holdings" data={{ labels, datasets }} centerLabel="$48k" />
```
