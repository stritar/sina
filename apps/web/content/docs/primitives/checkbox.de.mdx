`Checkbox` schaltet einen einzelnen booleschen Wert um. Sie unterstützt außerdem
einen **unbestimmten** Zustand für „einige, aber nicht alle", etwa ein
übergeordnetes Element, das eine Gruppe steuert.

## Verwendung

```tsx
import { Checkbox } from "@sina-design-system/core";

<Checkbox checked={agreed} onCheckedChange={setAgreed} label="I agree" />
<Checkbox checked="indeterminate" label="Select all" />
```

## Barrierefreiheit

`Space` schaltet um; das Label ist anklickbar; der Zustand wird als aktiviert,
deaktiviert oder gemischt angesagt.
