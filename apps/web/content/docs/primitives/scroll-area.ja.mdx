`ScrollArea` は、スクロール可能な領域に、ブラウザ間で一貫したスタイル付きのスクロールバーを提供します。ネイティブのキーボードスクロールを無効化することはありません。

## 使い方

```tsx
import { ScrollArea } from "@sina-design-system/core";

<ScrollArea style={{ height: 240 }}>
  {/* long content */}
</ScrollArea>
```

## アクセシビリティ

本来ならあふれてしまう、範囲の限られたリストやパネルに使用してください。コンテンツはキーボードでスクロール可能なままで、スクロールバーがレイアウトをずらすこともありません。
