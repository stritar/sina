`KpiStat` は重要な数字を 1 つ大きく表示し、オプションで比較値を付けられます。比較値はトレンドバッジとしてレンダリングされます（デフォルトでは上昇が良い状態です）。

## 使い方

```tsx
import { KpiStat } from "@sina-design-system/core";

<KpiStat
  value={12500}
  comparisonValue={11800}
  valueFormatter={(v) => `$${v.toLocaleString("en-US")}`}
  comparisonLabel="vs last month"
/>
```

## アクセシビリティ

下降トレンドは太字の下向きグリフを備えた危険バッジを使用するため、意味が色だけに依存することは決してありません。すべてが実際のテキストであり（画像なし、canvas なし）、サーバー側でマウント可能です（クライアント JS なし）。
