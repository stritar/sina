`DonutChart` es un [PieChart](/docs/primitives/pie-chart) con un recorte central,
para que puedas colocar un total o una etiqueta en el medio.

## Uso

```tsx
import { DonutChart } from "@sina-design-system/core";

<DonutChart label="Holdings" data={{ labels, datasets }} centerLabel="$48k" />
```

## Accesibilidad

Comparte la paleta segura para daltónicos y la accesibilidad de `role="img"` +
leyenda de texto de PieChart.
