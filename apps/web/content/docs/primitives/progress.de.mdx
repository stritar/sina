`Progress` zeigt an, wie weit eine Aufgabe fortgeschritten ist. Übergeben Sie einen
`value` für einen bestimmten Fortschritt; lassen Sie ihn weg für einen unbestimmten Balken.

## Verwendung

```tsx
import { Progress } from "@sina-design-system/core";

<Progress value={62} />      {/* 62% */}
<Progress />                 {/* indeterminate */}
```

/ `aria-valuemin` / `aria-valuemax`.
