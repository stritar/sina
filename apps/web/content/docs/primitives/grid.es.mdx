`Grid` organiza los elementos hijos en columnas que se ajustan, con un `gap` de la
escala de espaciado. Úsalo para cuadrículas de tarjetas y paneles; usa [Stack](/docs/primitives/stack)
para una sola fila o columna.

## Uso

```tsx
import { Grid } from "@sina-design-system/core";

<Grid cols={3} gap={4}>
  {items.map((i) => <Card key={i.id} {...i} />)}
</Grid>
```

## Accesibilidad

Puramente presentacional. Renderiza un `div` simple sin semántica añadida. Pasa
`as` para conservar una estructura significativa cuando las celdas son una colección
real (p. ej. `as="ul"`).
