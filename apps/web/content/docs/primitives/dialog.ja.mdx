`Dialog` は、フォーカスをトラップし、`Esc` で閉じ、フォーカスをトリガーへ戻すモーダルです。統制されたコンポーネント（`SecureWireDialog`
など）が構築の土台とするものです。

## 使い方

```tsx
import {
  Dialog, DialogTrigger, DialogContent, DialogTitle, DialogDescription, DialogClose,
} from "@sina-design-system/core";

<Dialog open={open} onOpenChange={setOpen}>
  <DialogContent>
    <DialogTitle>Confirm</DialogTitle>
    <DialogDescription>This can't be undone.</DialogDescription>
    <DialogClose asChild><Button variant="secondary">Cancel</Button></DialogClose>
  </DialogContent>
</Dialog>
```

## パーツ

`Dialog` · `DialogTrigger` · `DialogContent` · `DialogTitle` · `DialogDescription`
· `DialogClose`.

## アクセシビリティ

`aria-modal` を伴う `role="dialog"`、`aria-labelledby` で結び付けられたタイトル、フォーカストラップ、`Esc`
での閉じる操作、そして閉じるときのフォーカス復元を備えます。`DialogTitle` は必須で、アクセシブルな名前になります。
