`Separator` 在各区块之间绘制一条细线。默认情况下它是装饰性的（对屏幕阅读器隐藏）；
当分隔本身带有含义时，将其标记为非装饰性。

## 用法

```tsx
import { Separator } from "@sina-design-system/core";

<Separator />
<Separator orientation="vertical" />
```

## 无障碍

装饰性分隔线对辅助技术隐藏。设置 `decorative={false}` 后，分隔线会暴露
`role="separator"`，作为真正的区块边界。
