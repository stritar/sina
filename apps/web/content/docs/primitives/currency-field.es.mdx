`CurrencyField` da formato a un importe monetario como esperarías, agrupando los
miles al perder el foco, y manteniendo un valor numérico limpio por debajo.

## Uso

```tsx
import { CurrencyField } from "@sina-design-system/core";

<CurrencyField label="Amount" currencySymbol="$" defaultValue="25000" />
```
