`PieChart` shows how a whole splits into parts. Slices draw from the
`--sina-color-chart--1…8` palette, ordered for color-blind safety. For a
centered summary figure, use [DonutChart](/docs/primitives/donut-chart).

## Usage

```tsx
import { PieChart } from "@sina-design-system/core";

<PieChart label="Portfolio allocation" data={{ labels, datasets }} />
```
