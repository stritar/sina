---
title: PieChart
description: A part-to-whole chart (Chart.js). Slices use the color-blind-safe dataviz palette.
---

`PieChart` shows how a whole splits into parts. Slices draw from the
`--sina-color-chart--1…8` palette, ordered for color-blind safety.

```tsx
import { PieChart } from "@sina-design-system/core";

<PieChart label="Portfolio allocation" data={/* Chart.js data */} />
```
