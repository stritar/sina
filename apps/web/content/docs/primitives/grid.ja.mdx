`Grid` は子要素を折り返す列に配置し、間隔スケールの `gap` を使用します。カードグリッドやダッシュボードに使用してください。単一の行または列には [Stack](/docs/primitives/stack) を使用します。

## 使い方

```tsx
import { Grid } from "@sina-design-system/core";

<Grid cols={3} gap={4}>
  {items.map((i) => <Card key={i.id} {...i} />)}
</Grid>
```

## アクセシビリティ

純粋に表示用です。セマンティクスを追加せず、単純な `div` をレンダリングします。セルが実際のコレクションである場合は、`as` を渡して意味のある構造を保ってください（例: `as="ul"`）。
