`Checkbox` bascule une seule valeur booléenne. Il prend aussi en charge un état
**indéterminé** pour « certains mais pas tous », comme un élément parent qui
contrôle un groupe.

## Utilisation

```tsx
import { Checkbox } from "@sina-design-system/core";

<Checkbox checked={agreed} onCheckedChange={setAgreed} label="I agree" />
<Checkbox checked="indeterminate" label="Select all" />
```

## Accessibilité

`Space` bascule ; le libellé est cliquable ; l'état est annoncé comme coché,
décoché ou mixte.
