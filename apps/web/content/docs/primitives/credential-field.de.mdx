`CredentialField` maskiert ein Geheimnis während der Eingabe. Seine
Begleitkomponente `CredentialOTP` rendert ein segmentiertes Eingabefeld für
Einmalcodes, den zweiten Faktor in SINAs geregelten Freigabeabläufen.

## Verwendung

```tsx
import { CredentialField, CredentialOTP } from "@sina-design-system/core";

<CredentialField label="API key" />
<CredentialOTP length={6} onComplete={verify} />
```
