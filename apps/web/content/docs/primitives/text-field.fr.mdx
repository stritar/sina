`TextField` est un champ de saisie de texte avec tout le câblage de Field
déjà intégré. Activez `multiline` pour obtenir un textarea.

## Utilisation

```tsx
import { TextField } from "@sina-design-system/core";

<TextField label="Name" placeholder="Ada Lovelace" />
<TextField label="Notes" multiline />
```
