`PieChart` 展示一个整体如何拆分为各个部分。切片取自
`--sina-color-chart--1…8` 调色板，其顺序针对色盲安全进行了排序。若需要居中的
汇总数字，请使用 [DonutChart](/docs/primitives/donut-chart)。

## 用法

```tsx
import { PieChart } from "@sina-design-system/core";

<PieChart label="Portfolio allocation" data={{ labels, datasets }} />
```
