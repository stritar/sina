`Badge` ist ein kleiner Chip, der den Status von etwas inline kennzeichnet: eine Zeile, eine
Karte, eine Überschrift.

## Verwendung

```tsx
import { Badge } from "@sina-design-system/core";

<Badge intent="success">Verified</Badge>
<Badge intent="danger" dot>Blocked</Badge>
```

<Callout variant="note" title="Statusregeln gelten">
  Ein `danger`- oder `warning`-Badge rendert automatisch ein fettes Glyph. Und ein Badge ist ein
  Statuselement, rendere es also niemals innerhalb eines Alert oder Toast. Platziere es als Geschwisterelement.
</Callout>

## Barrierefreiheit

Bedeutung wird niemals allein durch Farbe transportiert. Ein Schweregrad-Badge kombiniert seinen
Farbton stets mit einem Glyph oder Punkt sowie einer Textbeschriftung. Die Schließen-Schaltfläche eines
schließbaren Badge nimmt ein explizites `closeLabel` entgegen.
