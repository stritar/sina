`Checkbox` alterna un único valor booleano. También admite un estado
**indeterminado** para "algunos pero no todos", como un elemento padre que
controla un grupo.

## Uso

```tsx
import { Checkbox } from "@sina-design-system/core";

<Checkbox checked={agreed} onCheckedChange={setAgreed} label="I agree" />
<Checkbox checked="indeterminate" label="Select all" />
```

## Accesibilidad

`Space` alterna; la etiqueta es clicable; el estado se anuncia como marcado, no
marcado o mixto.
