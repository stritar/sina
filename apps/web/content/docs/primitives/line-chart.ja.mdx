`LineChart` は 1 つ以上の系列を時系列でプロットし、ホバー時のツールチップはトークンからスタイリングされます。エリアチャートにするには `fill` を渡します。

## 使い方

```tsx
import { LineChart } from "@sina-design-system/core";

<LineChart
  label="Balance over time"
  data={{ labels, datasets }}
  valueFormatter={(n) => `$${n.toLocaleString()}`}
  fill
/>
```

## アクセシビリティ

`"use client"` コンポーネント（canvas）です。ラッパーはあなたの `label` を持つ `role="img"` です。非視覚的な経路として、近くにテキスト要約を保ってください。視覚効果を減らす設定ではアニメーションが無効になります。
