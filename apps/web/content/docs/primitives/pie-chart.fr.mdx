`PieChart` montre comment un tout se répartit en parties. Les parts sont tirées
de la palette `--sina-color-chart--1…8`, ordonnée pour être sûre pour les
daltoniens. Pour un chiffre de synthèse centré, utilisez
[DonutChart](/docs/primitives/donut-chart).

## Utilisation

```tsx
import { PieChart } from "@sina-design-system/core";

<PieChart label="Portfolio allocation" data={{ labels, datasets }} />
```
