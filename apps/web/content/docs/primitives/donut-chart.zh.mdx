`DonutChart` 是带有中心镂空的 [PieChart](/docs/primitives/pie-chart)，因此你可以在中间放置总计或标签。

## 用法

```tsx
import { DonutChart } from "@sina-design-system/core";

<DonutChart label="Holdings" data={{ labels, datasets }} centerLabel="$48k" />
```
