`BarChart` vergleicht Werte über Kategorien hinweg. Aktivieren Sie `horizontal`
für lange Beschriftungen und `stacked`, um die Zusammensetzung darzustellen.

## Verwendung

```tsx
import { BarChart } from "@sina-design-system/core";

<BarChart
  label="Spending by category"
  data={{ labels, datasets }}
  horizontal
  valueFormatter={(n) => `$${n}`}
/>
```
