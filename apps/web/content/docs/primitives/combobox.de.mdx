`Combobox` ist ein Select, in das du tippen kannst. Verwende es, wenn die
Optionsliste lang genug ist, dass das Durchsuchen eines Dropdowns mühsam wird.

## Verwendung

```tsx
import { Combobox } from "@sina-design-system/core";

<Combobox
  options={[
    { value: "usd", label: "US Dollar" },
    { value: "eur", label: "Euro" },
  ]}
  value={currency}
  onValueChange={setCurrency}
  placeholder="Search currencies"
/>
```

## Barrierefreiheit

Basiert auf einem Popover mit einem nativen Input. Pfeiltasten bewegen sich durch
die Treffer, `Enter` wählt aus, und die Listbox wird Screenreadern angesagt.
