`TextField` is a text input with all the Field wiring built in. Set `multiline`
for a textarea.

## Usage

```tsx
import { TextField } from "@sina-design-system/core";

<TextField label="Name" placeholder="Ada Lovelace" />
<TextField label="Notes" multiline />
```
