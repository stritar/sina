`LineChart` traza una o varias series a lo largo del tiempo, con tooltips al pasar
el cursor estilizados a partir de tokens. Pasa `fill` para un gráfico de área.

## Uso

```tsx
import { LineChart } from "@sina-design-system/core";

<LineChart
  label="Balance over time"
  data={{ labels, datasets }}
  valueFormatter={(n) => `$${n.toLocaleString()}`}
  fill
/>
```

## Accesibilidad

Un componente `"use client"` (canvas). El contenedor es `role="img"` con tu
`label`; mantén un resumen de texto cerca como ruta no visual. La animación se
desactiva con movimiento reducido.
