`Badge` は、行内で何かのステータスをラベル付けする小さなチップです。行、カード、見出しなどに使います。

## 使い方

```tsx
import { Badge } from "@sina-design-system/core";

<Badge intent="success">Verified</Badge>
<Badge intent="danger" dot>Blocked</Badge>
```

<Callout variant="note" title="ステータスのルールが適用されます">
  `danger` または `warning` の Badge は、太字の字形を自動的にレンダリングします。また Badge は
  ステータス要素なので、Alert や Toast の内部には決してレンダリングしないでください。兄弟要素として配置してください。
</Callout>

## アクセシビリティ

意味が色だけで伝えられることは決してありません。重大度を示す Badge は、その色合いを常に字形または
ドットとテキストラベルと組み合わせます。閉じることのできる Badge の閉じるボタンは、明示的な `closeLabel` を受け取ります。
