`Combobox` 是一个可以输入的选择框。当选项列表长到浏览下拉菜单变得麻烦时，就使用它。

## 用法

```tsx
import { Combobox } from "@sina-design-system/core";

<Combobox
  options={[
    { value: "usd", label: "US Dollar" },
    { value: "eur", label: "Euro" },
  ]}
  value={currency}
  onValueChange={setCurrency}
  placeholder="Search currencies"
/>
```
