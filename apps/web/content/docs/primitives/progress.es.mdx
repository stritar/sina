`Progress` muestra cuánto ha avanzado una tarea. Pasa un `value` para un progreso
determinado; omítelo para una barra indeterminada.

## Uso

```tsx
import { Progress } from "@sina-design-system/core";

<Progress value={62} />      {/* 62% */}
<Progress />                 {/* indeterminate */}
```

## Accesibilidad

Construido sobre Radix Progress con `role="progressbar"` y los valores correctos de
`aria-valuenow` / `aria-valuemin` / `aria-valuemax`.
