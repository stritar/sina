`Spinner` signalisiert, dass etwas passiert, du aber nicht weißt, wie lange es
dauern wird. Für eine bekannte Dauer verwende stattdessen [Progress](/docs/primitives/progress).

## Verwendung

```tsx
import { Spinner } from "@sina-design-system/core";

<Spinner size="md" label="Loading transactions" />
```

## Barrierefreiheit

Die Animation berücksichtigt `prefers-reduced-motion`. Übergib immer ein `label`,
damit die Wartezeit angesagt wird und nicht stumm bleibt.
