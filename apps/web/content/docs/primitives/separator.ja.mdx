`Separator` はセクションのあいだに細い罫線を引きます。デフォルトでは装飾的で
（スクリーンリーダーからは隠されます）、区切りが意味を持つ場合は非装飾的として
マークします。

## 使い方

```tsx
import { Separator } from "@sina-design-system/core";

<Separator />
<Separator orientation="vertical" />
```

## アクセシビリティ

装飾的なセパレーターは支援技術から隠されます。`decorative={false}` にすると、
区切り線は実際のセクション境界として `role="separator"` を公開します。
