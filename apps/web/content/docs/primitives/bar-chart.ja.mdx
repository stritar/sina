`BarChart` はカテゴリ間で値を比較します。長いラベルには `horizontal` を、構成を示すには `stacked` を切り替えます。

## 使い方

```tsx
import { BarChart } from "@sina-design-system/core";

<BarChart
  label="Spending by category"
  data={{ labels, datasets }}
  horizontal
  valueFormatter={(n) => `$${n}`}
/>
```
