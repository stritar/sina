`RadioGroup` sirve para una única elección exclusiva entre unas pocas opciones. Para más de un
puñado, es preferible [Select](/docs/primitives/select).

## Uso

```tsx
import { RadioGroup, RadioGroupItem } from "@sina-design-system/core";

<RadioGroup value={plan} onValueChange={setPlan}>
  <RadioGroupItem value="standard" label="Standard" />
  <RadioGroupItem value="priority" label="Priority" />
</RadioGroup>
```

## Accesibilidad

Sigue el patrón ARIA radiogroup: `Tab` entra en el grupo, las teclas de flecha se mueven
entre las opciones (foco itinerante) y solo la opción seleccionada es una parada de tabulación.
