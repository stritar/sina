`DonutChart` ist ein [PieChart](/docs/primitives/pie-chart) mit einer Aussparung,
sodass du eine Summe oder ein Label in die Mitte setzen kannst.

## Verwendung

```tsx
import { DonutChart } from "@sina-design-system/core";

<DonutChart label="Holdings" data={{ labels, datasets }} centerLabel="$48k" />
```
