`PieChart` muestra cómo un todo se divide en partes. Las porciones se dibujan a
partir de la paleta `--sina-color-chart--1…8`, ordenada para ser segura ante el
daltonismo. Para una cifra de resumen centrada, usa
[DonutChart](/docs/primitives/donut-chart).

## Uso

```tsx
import { PieChart } from "@sina-design-system/core";

<PieChart label="Portfolio allocation" data={{ labels, datasets }} />
```
