`BarChart` 用于跨类别比较数值。启用 `horizontal` 以适应长标签，启用 `stacked` 以展示构成。

## 用法

```tsx
import { BarChart } from "@sina-design-system/core";

<BarChart
  label="Spending by category"
  data={{ labels, datasets }}
  horizontal
  valueFormatter={(n) => `$${n}`}
/>
```
