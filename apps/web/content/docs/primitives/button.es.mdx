`Button` desencadena una acción: enviar un formulario, abrir un diálogo, confirmar
un paso. Usa un Button para las acciones y un enlace para la navegación.

## Uso

```tsx
import { Button } from "@sina-design-system/core";

<Button variant="primary" onClick={submit}>Continue</Button>
```

## Accesibilidad

Semántica nativa de `<button>`: enfocable, `Enter`/`Space` lo activan y se anuncia
`disabled`. Un botón de solo icono necesita un `aria-label`.
