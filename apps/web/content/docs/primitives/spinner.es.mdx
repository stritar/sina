`Spinner` indica que algo está ocurriendo, pero no sabes cuánto tiempo tardará.
Para una duración conocida, usa [Progress](/docs/primitives/progress) en su lugar.

## Uso

```tsx
import { Spinner } from "@sina-design-system/core";

<Spinner size="md" label="Loading transactions" />
```

## Accesibilidad

La animación respeta `prefers-reduced-motion`. Pasa siempre una `label` para que la
espera se anuncie, en lugar de ser silenciosa.
