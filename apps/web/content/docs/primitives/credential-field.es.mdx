`CredentialField` enmascara un secreto a medida que se escribe. Su componente
asociado `CredentialOTP` muestra un campo segmentado para códigos de un solo
uso, el segundo factor en los flujos de aprobación gobernados de SINA.

## Uso

```tsx
import { CredentialField, CredentialOTP } from "@sina-design-system/core";

<CredentialField label="API key" />
<CredentialOTP length={6} onComplete={verify} />
```
