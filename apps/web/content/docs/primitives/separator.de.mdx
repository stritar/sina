`Separator` zieht eine Haarlinie zwischen Abschnitten. Standardmäßig ist er
dekorativ (vor Screenreadern verborgen); markiere ihn als nicht dekorativ, wenn
die Trennung eine Bedeutung trägt.

## Verwendung

```tsx
import { Separator } from "@sina-design-system/core";

<Separator />
<Separator orientation="vertical" />
```

## Barrierefreiheit

Dekorative Trenner sind vor assistiver Technik verborgen. Mit
`decorative={false}` legt der Trenner `role="separator"` als echte
Abschnittsgrenze offen.
