`SummaryList` はラベル付きの値を適切な `<dl>` としてレンダリングします。統制されたダイアログが、あなたが承認しようとしている正確な条件を表示するために使うものです。

## 使い方

```tsx
import { SummaryList } from "@sina-design-system/core";

<SummaryList
  items={[
    { label: "Amount", value: "$60,000.00", emphasis: true },
    { label: "To", value: "Beta LLC" },
    { label: "Rail", value: "Wire" },
  ]}
/>
```

## アクセシビリティ

`<dl>`/`<dt>`/`<dd>` としてレンダリングされるため、ラベルと値の関係が支援技術に公開されます。
