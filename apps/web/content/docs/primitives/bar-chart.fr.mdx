`BarChart` compare des valeurs entre catégories. Activez `horizontal` pour les
libellés longs et `stacked` pour montrer la composition.

## Utilisation

```tsx
import { BarChart } from "@sina-design-system/core";

<BarChart
  label="Spending by category"
  data={{ labels, datasets }}
  horizontal
  valueFormatter={(n) => `$${n}`}
/>
```

## Accessibilité

Comme tous les graphiques canvas, c'est `"use client"`, `role="img"`, et il
s'accompagne d'un résumé textuel comme voie accessible.
