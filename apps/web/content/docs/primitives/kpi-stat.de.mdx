`KpiStat` zeigt eine wichtige Zahl groß an, mit einem optionalen Vergleich, der
als Trend-Badge dargestellt wird (standardmäßig ist ein Anstieg gut).

## Verwendung

```tsx
import { KpiStat } from "@sina-design-system/core";

<KpiStat
  value={12500}
  comparisonValue={11800}
  valueFormatter={(v) => `$${v.toLocaleString("en-US")}`}
  comparisonLabel="vs last month"
/>
```

## Barrierefreiheit

Ein fallender Trend verwendet ein Gefahren-Badge mit einem fetten Abwärts-Glyph,
sodass die Bedeutung nie allein auf der Farbe beruht. Alles ist echter Text (kein
Bild, kein Canvas) und serverseitig einbindbar (kein Client-JS).
