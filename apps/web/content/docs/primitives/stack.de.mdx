`Stack` ordnet seine Kinder entlang einer einzelnen Achse an, mit einem `gap` aus
der Abstandsskala. Es ist die alltägliche Layout-Primitive; greife zu
[Grid](/docs/primitives/grid), wenn du umbrechende Spalten brauchst.

## Verwendung

```tsx
import { Stack } from "@sina-design-system/core";

<Stack direction="row" gap={3} align="center">
  <Badge>Draft</Badge>
  <span>Invoice #204</span>
</Stack>
```

## Barrierefreiheit

Rein präsentational. Es rendert ein schlichtes `div` ohne zusätzliche Semantik.
Wenn die Kinder eine echte Struktur bilden, übergib `as`, um sie zu erhalten
(z. B. sorgt `as="ul"` mit `li`-Kindern dafür, dass eine Liste eine Liste bleibt).
