`SummaryList` rendert beschriftete Werte als ordnungsgemäße `<dl>`. Es ist das,
was ein geregelter Dialog verwendet, um die genauen Bedingungen anzuzeigen, die du
gerade genehmigst.

## Verwendung

```tsx
import { SummaryList } from "@sina-design-system/core";

<SummaryList
  items={[
    { label: "Amount", value: "$60,000.00", emphasis: true },
    { label: "To", value: "Beta LLC" },
    { label: "Rail", value: "Wire" },
  ]}
/>
```

## Barrierefreiheit

Wird als `<dl>`/`<dt>`/`<dd>` gerendert, sodass die Beziehung zwischen Beschriftung
und Wert für assistive Technologien zugänglich ist.
