`Field` 是每个输入控件都会使用的包装器。它渲染一个标签、一个可选的描述和错误，并克隆其子元素，用正确的
`id`、`aria-describedby` 和 `aria-invalid` 将它们连接起来。你无需手动传递 ID，即可获得正确的表单可访问性。

## 用法

```tsx
import { Field } from "@sina-design-system/core";

<Field label="Email" description="We'll never share it." error={errors.email}>
  <input type="email" name="email" />
</Field>
```
