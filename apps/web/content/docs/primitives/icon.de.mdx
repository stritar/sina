`Icon` umschließt ein Phosphor-Glyph und zwingt dich, eine Frage zu beantworten: *bedeutet* dieses
Icon etwas, oder ist es Dekoration? Das richtig zu treffen, ist der Unterschied zwischen
einem zugänglichen und einem verwirrenden Icon.

## Verwendung

```tsx
import { Icon } from "@sina-design-system/core";
import { ShieldCheck } from "@phosphor-icons/react";

<Icon icon={ShieldCheck} label="Governed by SINA" />   {/* announced */}
<Icon icon={ShieldCheck} decorative />                 {/* silent */}
```

## Barrierefreiheit

Gib genau eines von `label` oder `decorative` an. Ein bedeutungstragendes Icon ohne `label`
ist für Screenreader-Nutzer unsichtbar; ein dekoratives mit `label` ist Rauschen. Die Farbe
folgt `currentColor`, sodass das umgebende `text-*`-Token sie bestimmt.
