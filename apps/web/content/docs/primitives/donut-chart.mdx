---
title: DonutChart
description: A pie chart with a hole — room for a total or headline figure in the center.
---

`DonutChart` is a [PieChart](/docs/primitives/pie-chart) with a cutout, so you can
place a total or label in the middle.

```tsx
import { DonutChart } from "@sina-design-system/core";

<DonutChart label="Holdings" data={/* Chart.js data */} centerLabel="$48k" />
```
