`Combobox` は入力できるセレクトです。選択肢のリストが長く、ドロップダウンを見て探すのが大変なときに使います。

## 使い方

```tsx
import { Combobox } from "@sina-design-system/core";

<Combobox
  options={[
    { value: "usd", label: "US Dollar" },
    { value: "eur", label: "Euro" },
  ]}
  value={currency}
  onValueChange={setCurrency}
  placeholder="Search currencies"
/>
```

## アクセシビリティ

ネイティブの input を備えた Popover の上に構築されています。矢印キーで一致項目を移動し、`Enter` で選択、listbox はスクリーンリーダーに読み上げられます。
