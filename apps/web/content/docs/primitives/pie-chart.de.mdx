`PieChart` zeigt, wie sich ein Ganzes in Teile aufteilt. Die Segmente stammen aus
der Palette `--sina-color-chart--1…8`, in einer für Farbenblinde sicheren
Reihenfolge angeordnet. Für eine zentrierte Zusammenfassungszahl verwenden Sie
[DonutChart](/docs/primitives/donut-chart).

## Verwendung

```tsx
import { PieChart } from "@sina-design-system/core";

<PieChart label="Portfolio allocation" data={{ labels, datasets }} />
```
