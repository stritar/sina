`Chart` ist eine kompakte Sparkline für Inline-Trends. Es ist reines SVG,
gesteuert durch `currentColor`, sodass es auf dem Server gerendert wird und die
umgebende Textfarbe erbt. Für vollständige, interaktive Diagramme verwende
[LineChart](/docs/primitives/line-chart) und Verwandte.

## Verwendung

```tsx
import { Chart } from "@sina-design-system/core";

<Chart variant="area" data={[3, 5, 4, 8, 7, 11]} label="Balance trend, up" />
```

## Barrierefreiheit

Wird als `role="img"` mit einem erforderlichen Label gerendert. Reduziert sich bei
einem einzelnen Punkt auf eine flache Grundlinie.
