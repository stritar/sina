`Progress` はタスクの進捗状況を表示します。確定的な進捗には `value` を渡し、
不確定なバーの場合は省略します。

## 使い方

```tsx
import { Progress } from "@sina-design-system/core";

<Progress value={62} />      {/* 62% */}
<Progress />                 {/* indeterminate */}
```

## アクセシビリティ

Radix Progress をベースに構築され、`role="progressbar"` と正しい `aria-valuenow`
/ `aria-valuemin` / `aria-valuemax` を備えています。
