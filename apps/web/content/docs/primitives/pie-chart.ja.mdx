`PieChart` は、全体がどのように各部分に分割されるかを示します。スライスは
`--sina-color-chart--1…8` パレットから描画され、色覚安全のために順序付けられて
います。中央に配置された要約の数値には、[DonutChart](/docs/primitives/donut-chart)
を使用してください。

## 使い方

```tsx
import { PieChart } from "@sina-design-system/core";

<PieChart label="Portfolio allocation" data={{ labels, datasets }} />
```
