`Field` es el envoltorio que utiliza cada campo de entrada. Renderiza una
etiqueta, una descripción y un error opcionales, y clona su hijo para conectarlos
con el `id`, el `aria-describedby` y el `aria-invalid` correctos. Obtienes una
accesibilidad de formulario correcta sin tener que enlazar los IDs a mano.

## Uso

```tsx
import { Field } from "@sina-design-system/core";

<Field label="Email" description="We'll never share it." error={errors.email}>
  <input type="email" name="email" />
</Field>
```

<Callout variant="note" title="Los errores llevan un glifo">
  Cuando se establece `error`, Field renderiza el glifo de advertencia en negrita
  obligatorio junto al mensaje, nunca solo con color. Esa es una regla de SINA
  para los estados de error y advertencia.
</Callout>
