`CurrencyField` formatiert einen Geldbetrag wie erwartet, gruppiert beim
Verlassen des Felds die Tausenderstellen und behält darunter einen sauberen
numerischen Wert bei.

## Verwendung

```tsx
import { CurrencyField } from "@sina-design-system/core";

<CurrencyField label="Amount" currencySymbol="$" defaultValue="25000" />
```
