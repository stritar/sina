`Alert` comunica un estado persistente y en línea: una advertencia encima de un
formulario, una confirmación de éxito, la explicación de un error.

## Uso

```tsx
import { Alert } from "@sina-design-system/core";

<Alert variant="warning" title="Approval required">
  This transfer needs a second approver before it can proceed.
</Alert>
```

<Callout variant="warning" title="Dos reglas para el estado">
  Las alertas warning y danger **siempre** renderizan un glifo en negrita. Puedes
  cambiarlo pero no eliminarlo. Y nunca anides un elemento de estado dentro de
  otro: un Badge va *junto a* una Alert, no dentro de ella.
</Callout>

## Accesibilidad

Las alertas danger usan `role="alert"` (anunciado de forma asertiva); el resto usa
`role="status"` (cortés). El significado lo transmiten el icono + el título + el
texto, nunca solo el color.
