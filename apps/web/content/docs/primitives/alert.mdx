---
title: Alert
description: An inline status banner. Four severities, each with a bold status glyph so meaning never rests on color alone.
---

`Alert` communicates a persistent, inline status — a warning above a form, a
success confirmation, an error explanation.

```tsx
import { Alert } from "@sina-design-system/core";

<Alert variant="warning" title="Approval required">
  This transfer needs a second approver before it can proceed.
</Alert>
```

<Callout variant="warning" title="Two rules for status">
  Warning and danger alerts **always** render a bold glyph — you can swap it but
  not remove it. And never nest one status element inside another: a Badge belongs
  *beside* an Alert, not inside it.
</Callout>
