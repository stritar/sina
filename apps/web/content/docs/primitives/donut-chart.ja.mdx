`DonutChart` は中央にくり抜きのある [PieChart](/docs/primitives/pie-chart) です。中央に合計やラベルを配置できます。

## 使い方

```tsx
import { DonutChart } from "@sina-design-system/core";

<DonutChart label="Holdings" data={{ labels, datasets }} centerLabel="$48k" />
```

## アクセシビリティ

PieChart と同じ色覚多様性に配慮したパレットと、`role="img"` ＋テキスト凡例による
アクセシビリティを共有します。
