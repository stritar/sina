`Button` 触发一个动作：提交表单、打开对话框、确认某个步骤。用 Button 表示动作，
用链接表示导航。

## 用法

```tsx
import { Button } from "@sina-design-system/core";

<Button variant="primary" onClick={submit}>Continue</Button>
```

## 无障碍

原生 `<button>` 语义：可获得焦点，`Enter`/`Space` 触发，并会朗读 `disabled`。
仅含图标的按钮需要一个 `aria-label`。
