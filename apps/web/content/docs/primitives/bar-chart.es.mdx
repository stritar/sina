`BarChart` compara valores entre categorías. Activa `horizontal` para etiquetas
largas y `stacked` para mostrar la composición.

## Uso

```tsx
import { BarChart } from "@sina-design-system/core";

<BarChart
  label="Spending by category"
  data={{ labels, datasets }}
  horizontal
  valueFormatter={(n) => `$${n}`}
/>
```

## Accesibilidad

Como todos los gráficos de canvas, es `"use client"`, `role="img"` y se acompaña
de un resumen de texto como ruta accesible.
