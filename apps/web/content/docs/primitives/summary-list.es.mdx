`SummaryList` renderiza valores etiquetados como un `<dl>` correcto. Es lo que un
diálogo gobernado usa para mostrar los términos exactos que estás aprobando.

## Uso

```tsx
import { SummaryList } from "@sina-design-system/core";

<SummaryList
  items={[
    { label: "Amount", value: "$60,000.00", emphasis: true },
    { label: "To", value: "Beta LLC" },
    { label: "Rail", value: "Wire" },
  ]}
/>
```

## Accesibilidad

Se renderiza como `<dl>`/`<dt>`/`<dd>`, de modo que la relación etiqueta/valor queda
expuesta a la tecnología asistiva.
