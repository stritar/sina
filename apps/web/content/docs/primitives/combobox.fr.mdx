`Combobox` est un select dans lequel vous pouvez taper. Utilisez-le lorsque la
liste d'options est assez longue pour que parcourir un menu déroulant devienne
pénible.

## Utilisation

```tsx
import { Combobox } from "@sina-design-system/core";

<Combobox
  options={[
    { value: "usd", label: "US Dollar" },
    { value: "eur", label: "Euro" },
  ]}
  value={currency}
  onValueChange={setCurrency}
  placeholder="Search currencies"
/>
```

## Accessibilité

Construit sur un Popover avec un input natif. Les touches fléchées parcourent les
correspondances, `Enter` sélectionne, et la listbox est annoncée aux lecteurs
d'écran.
