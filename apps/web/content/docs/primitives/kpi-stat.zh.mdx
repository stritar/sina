`KpiStat` 以醒目的大字显示一个重要的数字，并可选地附带一个比较值，该比较值会渲染为趋势徽章（默认上升为好）。

## 用法

```tsx
import { KpiStat } from "@sina-design-system/core";

<KpiStat
  value={12500}
  comparisonValue={11800}
  valueFormatter={(v) => `$${v.toLocaleString("en-US")}`}
  comparisonLabel="vs last month"
/>
```

## 无障碍

下降趋势使用带有粗体向下字形的危险徽章，因此含义绝不会仅依赖颜色。所有内容都是真实文本（无图像、无 canvas），并且可以在服务器端挂载（无客户端 JS）。
