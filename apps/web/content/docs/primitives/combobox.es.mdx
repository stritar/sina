`Combobox` es un select en el que puedes escribir. Úsalo cuando la lista de
opciones sea lo bastante larga como para que recorrer un desplegable resulte
molesto.

## Uso

```tsx
import { Combobox } from "@sina-design-system/core";

<Combobox
  options={[
    { value: "usd", label: "US Dollar" },
    { value: "eur", label: "Euro" },
  ]}
  value={currency}
  onValueChange={setCurrency}
  placeholder="Search currencies"
/>
```

## Accesibilidad

Construido sobre un Popover con un input nativo. Las teclas de flecha recorren las
coincidencias, `Enter` selecciona y el listbox se anuncia a los lectores de
pantalla.
