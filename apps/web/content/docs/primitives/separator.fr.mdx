`Separator` trace un filet entre les sections. Par défaut il est décoratif
(masqué aux lecteurs d'écran) ; marquez-le comme non décoratif lorsque la
séparation porte du sens.

## Utilisation

```tsx
import { Separator } from "@sina-design-system/core";

<Separator />
<Separator orientation="vertical" />
```

## Accessibilité

Les séparateurs décoratifs sont masqués aux technologies d'assistance. Avec
`decorative={false}`, le séparateur expose `role="separator"` comme une véritable
frontière de section.
