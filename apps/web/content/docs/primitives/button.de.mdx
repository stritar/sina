`Button` löst eine Aktion aus: ein Formular absenden, einen Dialog öffnen, einen
Schritt bestätigen. Verwende einen Button für Aktionen und einen Link für die
Navigation.

## Verwendung

```tsx
import { Button } from "@sina-design-system/core";

<Button variant="primary" onClick={submit}>Continue</Button>
```

## Barrierefreiheit

Native `<button>`-Semantik: fokussierbar, `Enter`/`Space` aktivieren, und
`disabled` wird angesagt. Ein reiner Icon-Button benötigt ein `aria-label`.
