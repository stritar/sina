`Spinner` indique qu'une opération est en cours, mais dont vous ignorez la durée.
Pour une durée connue, utilisez plutôt [Progress](/docs/primitives/progress).

## Utilisation

```tsx
import { Spinner } from "@sina-design-system/core";

<Spinner size="md" label="Loading transactions" />
```

## Accessibilité

L'animation respecte `prefers-reduced-motion`. Passez toujours un `label` pour que
l'attente soit annoncée, et non silencieuse.
