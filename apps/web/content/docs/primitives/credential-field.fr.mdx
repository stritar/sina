`CredentialField` masque un secret au fur et à mesure de la saisie. Son
composant compagnon `CredentialOTP` affiche un champ segmenté pour code à usage
unique, le second facteur dans les flux d'approbation gouvernés de SINA.

## Utilisation

```tsx
import { CredentialField, CredentialOTP } from "@sina-design-system/core";

<CredentialField label="API key" />
<CredentialOTP length={6} onComplete={verify} />
```
