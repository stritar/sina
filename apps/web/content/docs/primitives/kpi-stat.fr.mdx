`KpiStat` affiche un chiffre important, en grand, avec une comparaison facultative
qui se rend sous forme de badge de tendance (par défaut, la hausse est positive).

## Utilisation

```tsx
import { KpiStat } from "@sina-design-system/core";

<KpiStat
  value={12500}
  comparisonValue={11800}
  valueFormatter={(v) => `$${v.toLocaleString("en-US")}`}
  comparisonLabel="vs last month"
/>
```

## Accessibilité

Une tendance à la baisse utilise un badge de danger avec un glyphe descendant en
gras, de sorte que le sens ne repose jamais uniquement sur la couleur. Tout est du
texte réel (pas d'image, pas de canvas) et se monte côté serveur (pas de JS client).
