`TextField` es una entrada de texto con todo el cableado de Field ya
incorporado. Activa `multiline` para obtener un textarea.

## Uso

```tsx
import { TextField } from "@sina-design-system/core";

<TextField label="Name" placeholder="Ada Lovelace" />
<TextField label="Notes" multiline />
```
