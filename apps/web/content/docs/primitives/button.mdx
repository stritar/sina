title: Button

`Button` triggers an action — submit a form, open a dialog, confirm a step. Use a
Button for actions and a link for navigation.

```tsx
import { Button } from "@sina-design-system/core";

<Button variant="primary" onClick={submit}>Continue</Button>
<Button variant="secondary" iconLeft={<Icon …/>}>Back</Button>
<Button variant="danger" loading>Deleting…</Button>
```

## Accessibility

Native `<button>` semantics — focusable, `Enter`/`Space` activate, `disabled` is
announced. An icon-only button needs an `aria-label`.

See all [primitives](/docs/primitives).
