`Stack` distribuye sus hijos a lo largo de un único eje con un `gap` tomado de la
escala de espaciado. Es la primitiva de maquetación de uso diario; recurre a
[Grid](/docs/primitives/grid) cuando necesites columnas que se ajusten a varias líneas.

## Uso

```tsx
import { Stack } from "@sina-design-system/core";

<Stack direction="row" gap={3} align="center">
  <Badge>Draft</Badge>
  <span>Invoice #204</span>
</Stack>
```

## Accesibilidad

Puramente presentacional. Renderiza un `div` simple sin semántica añadida. Cuando
los hijos forman una estructura real, pasa `as` para conservarla (por ejemplo,
`as="ul"` con hijos `li` mantiene una lista como lista).
