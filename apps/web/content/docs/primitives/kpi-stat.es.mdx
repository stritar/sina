`KpiStat` muestra un número importante, en grande, con una comparación opcional
que se renderiza como una insignia de tendencia (por defecto, subir es bueno).

## Uso

```tsx
import { KpiStat } from "@sina-design-system/core";

<KpiStat
  value={12500}
  comparisonValue={11800}
  valueFormatter={(v) => `$${v.toLocaleString("en-US")}`}
  comparisonLabel="vs last month"
/>
```

## Accesibilidad

Una tendencia a la baja usa una insignia de peligro con un glifo descendente en
negrita, de modo que el significado nunca depende solo del color. Todo es texto
real (sin imagen, sin canvas) y se puede montar en el servidor (sin JS de cliente).
