`TextField` ist ein Texteingabefeld, in dem die gesamte Field-Verdrahtung
bereits eingebaut ist. Setze `multiline` für ein textarea.

## Verwendung

```tsx
import { TextField } from "@sina-design-system/core";

<TextField label="Name" placeholder="Ada Lovelace" />
<TextField label="Notes" multiline />
```
