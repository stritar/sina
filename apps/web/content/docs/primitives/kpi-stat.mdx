`KpiStat` shows one important number, big, with an optional comparison that
renders as a trend badge (up is good by default).

## Usage

```tsx
import { KpiStat } from "@sina-design-system/core";

<KpiStat
  value={12500}
  comparisonValue={11800}
  valueFormatter={(v) => `$${v.toLocaleString("en-US")}`}
  comparisonLabel="vs last month"
/>
```

## Accessibility

A falling trend uses a danger badge with a bold down-glyph, so meaning never rests
on color alone. Everything is real text (no image, no canvas), and it's
server-mountable (no client JS).
