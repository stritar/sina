`Spinner` は、何かが進行中であるものの、どれくらい時間がかかるか分からないことを示します。
所要時間が分かっている場合は、代わりに [Progress](/docs/primitives/progress) を使用してください。

## 使い方

```tsx
import { Spinner } from "@sina-design-system/core";

<Spinner size="md" label="Loading transactions" />
```

## アクセシビリティ

アニメーションは `prefers-reduced-motion` を尊重します。待機状態が無音ではなく読み上げられるよう、
常に `label` を渡してください。
