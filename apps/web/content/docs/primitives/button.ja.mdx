`Button` はアクションを起動します。フォームの送信、ダイアログのオープン、ステップの確定などです。
アクションには Button を、ナビゲーションにはリンクを使用します。

## 使い方

```tsx
import { Button } from "@sina-design-system/core";

<Button variant="primary" onClick={submit}>Continue</Button>
```

## アクセシビリティ

ネイティブの `<button>` セマンティクス。フォーカス可能で、`Enter`/`Space` で起動し、
`disabled` が読み上げられます。アイコンのみのボタンには `aria-label` が必要です。
