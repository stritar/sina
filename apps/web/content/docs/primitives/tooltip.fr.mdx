`Tooltip` affiche une petite indication lorsque l'utilisateur survole un contrôle
ou le met au focus. Utilisez-le pour clarifier un bouton à icône ou ajouter un
détail, jamais pour une information dont l'utilisateur a *besoin* pour accomplir une
tâche, car il est masqué par défaut et indisponible au toucher.

## Utilisation

```tsx
import {
  TooltipProvider, Tooltip, TooltipTrigger, TooltipContent,
} from "@sina-design-system/core";

<TooltipProvider>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button variant="ghost" aria-label="Info"><Icon …/></Button>
    </TooltipTrigger>
    <TooltipContent>Groups digits on blur.</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## Accessibilité

S'ouvre au survol **et** au focus clavier, se ferme avec `Esc` et est annoncé via
`aria-describedby`. Le déclencheur a toujours besoin de son propre libellé
accessible.
