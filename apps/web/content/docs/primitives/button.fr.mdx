`Button` déclenche une action : soumettre un formulaire, ouvrir une boîte de
dialogue, confirmer une étape. Utilisez un Button pour les actions et un lien pour
la navigation.

## Utilisation

```tsx
import { Button } from "@sina-design-system/core";

<Button variant="primary" onClick={submit}>Continue</Button>
```

## Accessibilité

Sémantique native de `<button>` : focusable, `Enter`/`Space` activent, et
`disabled` est annoncé. Un bouton composé uniquement d'une icône a besoin d'un
`aria-label`.
