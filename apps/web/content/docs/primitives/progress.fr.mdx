`Progress` indique l'avancement d'une tâche. Passez une `value` pour une progression
déterminée ; omettez-la pour une barre indéterminée.

## Utilisation

```tsx
import { Progress } from "@sina-design-system/core";

<Progress value={62} />      {/* 62% */}
<Progress />                 {/* indeterminate */}
```

## Accessibilité

Construit sur Radix Progress avec `role="progressbar"` et les valeurs correctes
`aria-valuenow` / `aria-valuemin` / `aria-valuemax`.
