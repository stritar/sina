`Separator` traza una línea fina entre secciones. De forma predeterminada es
decorativo (oculto para los lectores de pantalla); márcalo como no decorativo
cuando la división tenga significado.

## Uso

```tsx
import { Separator } from "@sina-design-system/core";

<Separator />
<Separator orientation="vertical" />
```

## Accesibilidad

Los separadores decorativos se ocultan a la tecnología de asistencia. Con
`decorative={false}` el divisor expone `role="separator"` como un límite de
sección real.
