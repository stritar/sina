`CurrencyField` は、金額を期待どおりに整形し、フォーカスが外れたときに千の位を区切りながら、その下にクリーンな数値を保持します。

## 使い方

```tsx
import { CurrencyField } from "@sina-design-system/core";

<CurrencyField label="Amount" currencySymbol="$" defaultValue="25000" />
```

  これは表示専用です。上限を超える金額を止めることはありません。それはサーバー上のゲートの役割です。クライアント側の入力は常に回避され得るため、SINA は上限のためにそれを信頼することは決してありません。
