`Dialog` es un modal que atrapa el foco, se cierra con `Esc` y devuelve el foco al
disparador. Es la base sobre la que se construyen los componentes gobernados (como
`SecureWireDialog`).

## Uso

```tsx
import {
  Dialog, DialogTrigger, DialogContent, DialogTitle, DialogDescription, DialogClose,
} from "@sina-design-system/core";

<Dialog open={open} onOpenChange={setOpen}>
  <DialogContent>
    <DialogTitle>Confirm</DialogTitle>
    <DialogDescription>This can't be undone.</DialogDescription>
    <DialogClose asChild><Button variant="secondary">Cancel</Button></DialogClose>
  </DialogContent>
</Dialog>
```

## Partes

`Dialog` · `DialogTrigger` · `DialogContent` · `DialogTitle` · `DialogDescription`
· `DialogClose`.

## Accesibilidad

`role="dialog"` con `aria-modal`, un título conectado mediante `aria-labelledby`, una
trampa de foco, `Esc` para cerrar y la restauración del foco al cerrar. `DialogTitle`
es obligatorio; es el nombre accesible.
