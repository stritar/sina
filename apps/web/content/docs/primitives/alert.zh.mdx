`Alert` 传达一种持久的内联状态：表单上方的警告、成功确认或错误说明。

## 用法

```tsx
import { Alert } from "@sina-design-system/core";

<Alert variant="warning" title="Approval required">
  This transfer needs a second approver before it can proceed.
</Alert>
```

<Callout variant="warning" title="状态的两条规则">
  warning 和 danger 警报**始终**渲染粗体字形。你可以替换它，但不能移除它。并且切勿将一个状态元素嵌套在另一个之内：Badge 应*位于* Alert 旁边，而不是在其内部。
</Callout>

## 无障碍

danger 警报使用 `role="alert"`（以断言方式播报）；其余使用 `role="status"`（礼貌方式）。含义由图标 + 标题 + 文本共同传达，绝不仅凭颜色。
