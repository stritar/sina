`CurrencyField` met en forme un montant monétaire comme on s'y attend, en
groupant les milliers à la perte du focus, tout en conservant une valeur
numérique propre en dessous.

## Utilisation

```tsx
import { CurrencyField } from "@sina-design-system/core";

<CurrencyField label="Amount" currencySymbol="$" defaultValue="25000" />
```
