---
title: Stack
description: One-axis flex layout — line things up in a row or a column with consistent spacing from the token scale.
---

`Stack` lays out its children along a single axis with a `gap` drawn from the
spacing scale. It's the everyday layout primitive; reach for
[Grid](/docs/primitives/grid) when you need wrapping columns.

```tsx
import { Stack } from "@sina-design-system/core";

<Stack direction="row" gap={3} align="center">
  <Badge>Draft</Badge>
  <span>Invoice #204</span>
</Stack>
```
