`Alert` kommuniziert einen dauerhaften, eingebetteten Status: eine Warnung über
einem Formular, eine Erfolgsbestätigung, die Erklärung eines Fehlers.

## Verwendung

```tsx
import { Alert } from "@sina-design-system/core";

<Alert variant="warning" title="Approval required">
  This transfer needs a second approver before it can proceed.
</Alert>
```

<Callout variant="warning" title="Zwei Regeln für den Status">
  Alerts mit warning und danger rendern **immer** ein fettes Glyph. Sie können es
  austauschen, aber nicht entfernen. Und verschachteln Sie niemals ein
  Status-Element in einem anderen: ein Badge gehört *neben* einen Alert, nicht
  hinein.
</Callout>

## Barrierefreiheit

danger-Alerts verwenden `role="alert"` (assertiv angekündigt); die übrigen
verwenden `role="status"` (höflich). Die Bedeutung wird durch Symbol + Titel +
Text vermittelt, niemals allein durch Farbe.
